Set up your Claude assistant

About 20 minutes, once per computer. Work top to bottom; tick each step as you go. Your ticks are remembered on this device.

  1. Create a GitHub account

    GitHub is where your work gets backed up. It's free. Already have one? Tick this and move on.

    Create GitHub account
    • Pick a simple username. You'll type it again in step 6.
    • Enter the code GitHub emails you. Choose the Free plan; skip the questions about teams.
    • When asked to turn on two-factor sign-in, do it, and keep the recovery codes somewhere safe.

  2. Get a Claude plan

    The assistant needs a Pro plan or higher. Sign up with the email you'll use day to day.

    Open Claude

  3. Install VS Code

    This is the app you'll work in.

    Download VS Code

    Then open VS Code, press Cmd+Shift+P, type Shell Command: Install 'code' command in PATH, and press Enter.

  4. Add Claude to VS Code

    With VS Code installed, this button opens it straight to the Claude Code extension. Click Install.

    Open in VS Code Button didn't work?

  5. Install two small tools

    Git (keeps your history). Open the Terminal app (press Cmd+Space, type Terminal), paste this, press Enter, and click Install in the box that appears:

    xcode-select --install

    If it says it's already installed, you're set.

    GitHub CLI (signs you in to GitHub). Download the Mac installer and open it:

    Git for Windows. Install it with the default options. It also gives you Git Bash, which you'll use below.

    Download Git for Windows

    GitHub CLI (signs you in to GitHub). Download the Windows installer and run it:

    Download GitHub CLI

  6. Make your own copy of the workspace

    Sign in to GitHub first. This button opens a "new repository" page with everything pre-filled.

    Make my copy
    • Give it a short name with no spaces, like my-studio.
    • Set it to Private, then click Create repository.

    Fill these in and the commands in the next step update themselves.

  7. Download it and run setup

    In TerminalGit Bash, paste each line and press Enter, one at a time.

    First, sign in. Choose GitHub.com → HTTPS → Yes → Login with a web browser, then enter the code it shows you.

    gh auth login
    cd ~/Documents
    gh repo clone YOUR-USERNAME/YOUR-REPO-NAME
    cd YOUR-REPO-NAME
    bash scripts/setup.sh

    When setup asks about the wrong-folder guard, press Enter for yes. It puts a shortcut to your workspace on your Desktop.

  8. Meet your assistant

    Double-click the workspace shortcut on your Desktop. In VS Code, click the Claude icon (top right), sign in with your Claude account, and send this:

    Read START_HERE.md and begin onboarding.

    Claude will interview you for 10 to 15 minutes about you and your work, then ask what you want to build first.

Every time after that

  • Always open the Desktop shortcut, not plain VS Code. Opened any other way, Claude can't see your files and nothing gets backed up.
  • Just say what you want to work on. Claude checks for unsaved work and syncs on its own.
  • When a box asks about git push, that's your backup to GitHub. Click Yes.
  • When you're done for the day, say "save and back up."

If something goes wrong

Claude says it's in the wrong folderClose that window and open the Desktop shortcut.
Claude can't reach GitHubIn your folder, run bash scripts/setup.sh again to sign back in.
"git-bash required" (Windows)Install Git for Windows (step 5), then quit and reopen VS Code.
A command says "not found"Close Terminal, open a new one, and try again. New installs show up in new windows.
Anything elseDescribe it to Claude, or message the person who sent you this page.
